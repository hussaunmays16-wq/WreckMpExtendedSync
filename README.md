# WreckMP Extended Sync

**WreckMP Extended Sync** — модификация для кооперативного режима [My Summer Car](https://store.steampowered.com/app/516750/My_Summer_Car/) поверх WreckMP, обеспечивающая расширенную синхронизацию игрового мира.

- **Версия:** 3.9.4
- **Что делает:** Синхронизирует каталоги заказов, посылки и почту Теймо, предметы в руках и кастомные спавны, чемодан с деньгами, телефонные звонки и общую экономику между игроками в реальном времени. Вся транспортная синхронизация оставлена штатному ядру WreckMP для максимальной стабильности физики.
- **Требования:**
  - My Summer Car
  - MSCLoader (0.4.x+)
  - WreckMP (v0.2.15)
  - BetterCheatBox
- **Установка:**
  1. Соберите проект или скачайте готовый `WreckMPExtendedSync.dll`.
  2. Скопируйте файл `WreckMPExtendedSync.dll` в папку `Mods/` вашей игры My Summer Car.
  3. Запустите игру вместе с WreckMP и наслаждайтесь совместной игрой.
